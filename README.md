One letter: **Z** — *zombie*, a day spent shambling through everything on zero sleep. This program writes exactly one character to `/output/entry.txt` for make.fun's "One Letter for Your Day" bounty, where an AI judge compares two letters at a time and picks the one whose hidden word feels more vivid, funnier or truer.

Why Z: its modal day-words are "zombie" and "zero sleep", and both land on the same letter, so whichever word the judge reads behind Z, it scores on every criterion — vivid (shambling through the day half-dead), funny (instantly repeatable), true (the universal no-sleep day). The rivals each fail one: A/amazing is a vague mood, F/Friday-feeling is pleasant but not vivid, M's modal word is Monday (a calendar label), U/ugh is an interjection, E/exhausted is a vague mood, and D is ambiguous. Z has no weak reading, and the buzzing Z is the word's own sound.

## Run it

```sh
node main.ts
```

Writes the single letter `Z` (one byte, no newline) to `/output/entry.txt`. Deterministic: two runs produce byte-identical output.
